# results/

The data behind [RESULTS.md](RESULTS.md), the summary: every number there names the run or report it comes from. The model is described in [docs/MODEL.md](../docs/MODEL.md).

**A run folder** holds `summary.md`, `summary.json`, `timeseries.csv`, `gangway_flows.csv` and the per-step checks' CSVs (empty when they pass). `heatmap.csv` is kept only for the four runs the peak-density figure reads; the same arguments reproduce it for any other run on the same driver.

**Literature values.** The literature thresholds shown in the figures (LoS E/F, crush density) are as reported in the cited sources and not yet checked against the originals. The same holds for the other literature values they show (Weidmann's diagram, the stair targets, the 8-minute reference).

**Commit IDs** in these files refer to the private development history; the public release is v1.0.

**Raw outputs are kept as the tools wrote them.** Run summaries, logs and probe reports may use development names, a local path and the folder layout they were written in. The tables listed above as generated by `tools/figures` use this layout.

New runs go under `out/results/` unless a script's output variable says otherwise, so they do not mix with these files.
