# Thesis figures (one GPU driver, one simulation code version)

Generated by `python tools/figures/thesis_figures.py` (style, language and definitions in its header) from the experiment matrix (`tools/experiment/thesis_matrix.sh`: runs under results/evacuation/matrix/; the model before the stair calibration, selected by --stair-flow off, runs under results/evacuation/matrix_before_calibration/; GPU, every per-step check on), its bottleneck analysis (`tools/figures/bottleneck.py` -> results/evacuation/matrix/bottleneck.json) and the harness runs named below. **cs/**: Czech (labels, legends, annotations; decimal comma, thin space as the thousands separator; no English words, no internal names); **en/**: English. The literature values they show are as reported in the cited sources, not yet checked against the originals (results/README.md). Each figure as PDF (vector, embedded fonts, for LaTeX), PNG (300 dpi) and SVG; 15 cm wide; subscripts by mathtext in the same face (t italic, the index upright); Linux Biolinum G (Libertinus Sans' parent face; Libertinus Sans is not installed); no titles baked in; tick labels never rounded (the script checks every numeric tick label against its location). Venue colours: S blue, M orange, L aqua, the terrace grey.

**GPU driver of every run and harness result: 4.3.0 Core Profile Context 26.10.1.261008** (AMD Radeon RX 7800 XT). Each figure's line names its runs and the commit their binary (run_experiment / fd_harness) was built at; every such binary has the same simulation code (results/evacuation/code_version_proof). Commit IDs refer to the private development history; the public release is v1.0. Numbers: results/RESULTS.md.
